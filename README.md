# 魔法元素學院 · Chemistry Lab

跟著像素門得列夫長老，把化學玩成魔法的互動教學網站。純前端、暗色魔法風格、手機與電腦皆可用。

🔗 線上版：https://cmyklisa.github.io/chemistry-lab/

## 五個階段

1. **認識元素** — 原子與電子的動畫教學、50 張元素性格卡、分族介紹
2. **翻牌記憶** — 符號↔中文／原子序／特性三種配對模式，難度可調，記翻牌次數與時間
3. **魔法混合實驗室** — 選兩個元素看反應、電子如何移動、危險等級，附對應特效
4. **對戰卡牌** — 對戰系統或雙人同機，能反應就把對方的牌炸掉
5. **元素魔術方塊** — 2×2 方塊，連鎖反應與炸彈拆除兩種玩法

全程有會走動、拍手、搖頭、撒花的 SVG 像素門得列夫陪伴，並有用 Web Audio API 即時合成的音效（右上角可靜音）。

## 技術

純 HTML / CSS / JavaScript，不需要建置工具、後端或資料庫。直接開 `index.html` 即可，或用任意靜態伺服器（例如 `python3 -m http.server`）。

## 本機預覽

```bash
python3 -m http.server 8000
# 開 http://localhost:8000
```
